# Source Register

The harvest step sweeps these every morning. Tier 1 is checked daily without fail;
Tier 2 is rotated (roughly half each day); Wildcard is a deliberate 3QD-style serendipity
slot — one item per issue from *outside* this list is encouraged.

Sources earn promotion/demotion based on the feedback log in PREFERENCES.md.
An item's *author* matters as much as its outlet — individual thinkers are first-class sources.

## Wildcard slot (3QD serendipity)

One item per issue may come from anywhere — 3QD itself, Marginal Revolution links, LRB/NYRB,
a YouTube lecture, a 15-year-old blog post — provided it clears the "would Jad forward this
to a friend?" bar. This slot exists so the newsletter never becomes a filter bubble.
